# Databricks Certified Data Engineer Associate 練習プロジェクト

新版（**2026年5月4日 改定版**・公式 exam guide の7領域）に準拠した、ローカルで動くクリック回答・自動採点の練習問題集です。インターネット接続・インストール不要。

---

## 使い方

1. `index.html` を **ダブルクリック** してブラウザ（Chrome / Edge など）で開く
2. モード・ドメイン・出題数を選んで「開始する」
3. 選択肢をクリックすると採点、結果画面でドメイン別スコアと解説を確認

**練習モード**：1問ごとに即時採点＋解説 / **試験モード**：最後にまとめて採点（本番と同じ45問も選択可）

---

## 主な機能

- クリック回答・自動採点、ドメイン別スコア、解説表示
- **出題順を3種類から選択**
  - 未出題を優先（推奨）… まだ解いていない問題から先に出し、一巡したら出題回数の少ない順
  - 完全ランダム … 毎回シャッフルして抽選
  - 固定順（ID順）… `questions.js` の並び順どおり（系統的に全問通すとき用）
- **問題一覧・成績ページ** … 全問の出題回数・正解回数・正答率を一覧表示（未出題/苦手フィルタ、「未出題だけ出題」ボタン付き）
- **解答履歴の保存**（受験回数・平均正答率・最高スコア・履歴一覧）
- **間違い問題の自動記録**（誤答した問題を蓄積、正解できたら自動で外れる）
- トップの **「間違い問題だけ復習」** からいつでも誤答だけを解き直せる／結果画面から「この回の間違いだけ復習」
- キーボード操作（数字で選択・Enterで次へ）、ダーク/ライト切替

> 履歴と間違い問題は **このブラウザ内** に保存されます（別PC・別ブラウザ・シークレットウィンドウには引き継がれません。ブラウザのサイトデータを消すとリセットされます）。

## 問題の追加方法

`questions.js` をメモ帳 / VS Code などで開き、`QUESTION_BANK` 配列の末尾（`];` の直前）に次の形式で追記して保存 → ブラウザを再読み込み。

```js
{
  id: 46,                       // 一意の番号（重複させない）
  domain: "jobs",               // 下のドメイン一覧のキーから選ぶ
  question: "問題文をここに",
  options: ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
  answer: 0,                    // 正解の位置（0=A, 1=B, 2=C, 3=D）
  explanation: "解説をここに"
},
```

- 選択肢は **2〜6個** まで（A〜Fを自動表示）
- コード例は `'シングルクォート'` を使うと書きやすい（例：`explode(col('items'))`）
- 各問オブジェクトの後ろのカンマ `,` を忘れずに

**合計：45問**（本番と同数）。公式 exam guide の出題観点（Auto Loader / COPY INTO / Lakeflow Connect、Lakeflow Jobs トリガー、Automation Bundle・CLI、Liquid Clustering・Predictive Optimization、Spark UI、列マスク・行フィルタ・ABAC など）を反映。

出題形式は**本番寄りの難度**に調整済み：シナリオ＋主に5択（A〜E）で、選択肢は正解に近いディストラクタ（SQL/PySpark の構文差、`explode`/`flatten` などの関数名、`IF NOT EXISTS`/`DELTA` 等のキーワード有無）で構成しています。
