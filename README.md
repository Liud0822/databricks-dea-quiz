# Databricks Certified Data Engineer Associate 練習プロジェクト

新版（**2026年5月4日 改定版**・公式 exam guide の7領域）に準拠した、ローカルで動くクリック回答・自動採点の練習問題集です。インストール不要（記録の永続化に Python 標準ライブラリのみ使用）。

---

## 使い方

**推奨：`start.bat` をダブルクリック**
ローカルサーバ（`serve.py`）が起動し、ブラウザで `http://127.0.0.1:8777/` が開きます。解答記録は `quiz.sqlite` に自動保存されます（ブラウザのキャッシュを消しても残る）。サーバのウィンドウを閉じると停止します。

> `index.html` を直接ダブルクリックしても動きます（サーバ無しモード）。その場合の記録はブラウザ内（localStorage）に保存され、サーバ利用時とは別管理になります。記録を一元管理したいので通常は `start.bat` から使ってください。

操作の流れ：モード・ドメイン・出題数を選んで「開始する」→ 選択肢をクリックで採点 → 結果画面でドメイン別スコアと解説を確認。

**練習モード**：1問ごとに即時採点＋解説 / **試験モード**：最後にまとめて採点（本番と同じ45問も選択可）

---

## 主な機能

- クリック回答・自動採点、ドメイン別スコア、解説表示
- **選択肢は毎回シャッフル表示**（正解の位置が固定されないため、位置で当て推量できない）
- **トップに章節別の正答率**（累計・重複含む）を表示
- 出題順を3種類から選択（未出題を優先／完全ランダム／固定順）
- **問題一覧・成績ページ**（全問の出題回数・正解回数・正答率、未出題/苦手フィルタ、一覧のCSV書き出し）
- 解答履歴・間違い問題の自動記録、**間違い問題だけ復習**、🚩マーク問題の復習
- **記録のバックアップ**：「記録をJSON保存」で `dea_state.json` を書き出し（別ブラウザ/別PCへの移行や退避用）
- キーボード操作（数字で選択・Enterで次へ・Mでマーク）、ダーク/ライト切替

## 記録の保存場所

- サーバ利用時（`start.bat`）… `quiz.sqlite`（`kv` テーブルにキー値で保存）。ブラウザのキャッシュ削除の影響を受けない。
- サーバ無し（`index.html` 直開き）… ブラウザの localStorage。
- どちらもキーは `dea_v2_stats`（成績）/`dea_v2_history`/`dea_v2_wrong`/`dea_v2_mark`/`dea_v2_attempts`。
- **記録（`quiz.sqlite` 等）は個人データのため `.gitignore` で除外**し、公開リポジトリには上げない。バックアップが要るときは「記録をJSON保存」で出した `dea_state.json` を安全な場所に退避する。

## バージョン管理（運用ルール）

複数の対話・端末での上書き事故を防ぐため、単独の git リポジトリで一元管理する。

```
git pull            # 編集前に最新を取得
# …index.html / questions.js などを編集…
git add -A && git commit -m "..." && git push
```

`quiz.sqlite`・`dea_state*.json`・`*.pdf` は `.gitignore` 済み（記録と著作権物はコミットしない）。

## 問題の追加方法

`questions.js` の `QUESTION_BANK` 配列の末尾（`];` の直前）に次の形式で追記して保存 → ブラウザを再読み込み。

```js
{
  id: 108,                      // 一意の番号（重複させない）
  domain: "jobs",               // 下のドメイン一覧のキーから選ぶ
  question: "問題文をここに",
  options: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  answer: 0,                    // 正解の位置（0始まり）
  explanation: "解説をここに",
  concept: "用語・関連知識の補足（任意）"
},
```

- 選択肢は **2〜6個**。表示時に毎回シャッフルされるので **`answer` の位置は自由**（0でよい）。
- **解説では選択肢を「A」「B」等の記号で参照しない**（シャッフルで位置が変わるため）。内容で説明する（例：「INTO を欠くと不可」）。
- コード例は `'シングルクォート'` を使うと書きやすい。各問オブジェクトの後ろのカンマを忘れずに。

## AI 分析（任意の併用ワークフロー）

App 本体の機能ではないが、記録が `quiz.sqlite`（標準的な SQLite）に貯まるので、AI アシスタント（Claude など）に `quiz.sqlite` を渡すと次のことができる：

- `kv` テーブルの `dea_v2_stats` 等を読み、**章節別の正答率・弱点ドメイン・繰り返し間違える問題**を分析
- その結果に基づき、**弱点を強化する問題を `questions.js` に追加**

`quiz.sqlite` は SQLite なので、`SELECT key,value FROM kv` で全記録を取り出せる（value は JSON 文字列）。分析はスナップショット（演習で日々変わる）である点に注意。
